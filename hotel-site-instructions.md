# Hotel Booking Website - Development Guide

## 🏗️ Architecture & Tech Stack
- **Core Framework:** Astro (for SEO, fast static rendering, and server endpoints).
- **Interactive UI:** SolidJS (used as Astro "Islands" for booking widgets, date pickers, etc.).
- **Database:** PostgreSQL (Recommended: Neon, Supabase, or Railway for connection pooling).
- **ORM:** Prisma (for type-safe database queries and migrations).
